# Contributing

Contributions are welcome. Discuss substantial changes before implementation, keep changes focused, and include tests for behavior changes. The binding compatibility and snapshot contract is [CONTRACT.md](CONTRACT.md).

Use Node.js 20 or later. From a clone, run `npm ci` and `node scripts/test.js`. Do not commit credentials or real server snapshots containing sensitive data. Check that documentation, examples, and behavior agree. Contributions are licensed under Apache-2.0; see [LICENSE](LICENSE).
