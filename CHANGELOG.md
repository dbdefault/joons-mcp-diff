## [0.1.0] - 2026-11-12 Preview

### Added

- Read-only MCP tool snapshots over stdio and HTTP.
- Compatibility comparison with BREAKING, NON_BREAKING, and UNKNOWN classifications, plus optional rename hints.
- Terminal, Markdown and JSON reports and configurable CI failure thresholds.
